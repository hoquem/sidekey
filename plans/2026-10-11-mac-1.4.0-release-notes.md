# Sidekey for Mac 1.4.0

## Custom layouts

Choose **Edit Layouts...** in the Sidekey menu to change what your keys do.

- Change, move, remove or reset any key, and add a layout for any app with **Add App...**. Changes reach the iPad or iPhone straight away.
- Set a key's label, icon, colour and action. Actions are a keyboard shortcut (record it or enter it by hand; the editor warns when macOS reserves the shortcut), a Windows shortcut, one of your Apple Shortcuts, or, for apps with several modes such as Citrix Viewer, a switch to another mode. Keys can also be set to need a press and hold.
- Custom keys cannot run shell commands or AppleScript. Built-in keys that run scripts can be replaced or removed, but not edited or moved.
- A key you edit that used to light with the app's state, such as Zoom's mute key, no longer lights with it.
- Layouts are saved in `~/Library/Application Support/Sidekey/Layouts/`. You can edit the files by hand and choose **Reload Layouts** to pick up the changes. Every file is checked each time it loads. A file with a problem is refused whole and reported in the menu and in the editor, where you can delete it.

## Fix

- Apple Shortcut keys now run the shortcuts tool directly instead of through a shell.

## iPad and iPhone

The iPad and iPhone app is unchanged. You do not need to update it.

## Updating

Sidekey does not update itself. Quit Sidekey, download the new `Sidekey.dmg` and drag Sidekey to Applications again, replacing the old copy.
