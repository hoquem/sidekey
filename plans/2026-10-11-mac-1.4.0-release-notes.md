# Sidekey for Mac 1.4.0

## Custom layouts

Choose **Edit Layouts...** in the Sidekey menu to change what your keys do.

- Change, move, remove and reset keys, and add a layout for any app with the **+** button under the app list; the **−** (minus) button removes one you added, after you confirm. Changes take effect at once and show on the iPad or iPhone when that app is in front. On a pinned layout, a key you changed, moved, removed or reset is refused until you unpin, bring the app to the front and pin again; keys you have not changed since pinning keep working. If you reset or remove a layout you added for an app, unpin it.
- Set a key's label, icon, colour and action. Actions are a keyboard shortcut (record it or enter it by hand; the editor warns when the shortcut is one macOS uses itself, such as Command-Space), a Windows shortcut, one of your Apple Shortcuts, or, for apps with several modes such as Citrix Viewer, a switch to another mode. Keys can also be set to need a press and hold.
- Custom keys cannot run shell commands or AppleScript themselves; an Apple Shortcut you choose runs whatever steps it contains. Built-in keys that run scripts can be replaced or removed, but not edited or moved.
- A key that lights with the app's state, such as Zoom's mute key or a Citrix mode key, stops lighting once you edit or move it.
- Layouts are saved in `~/Library/Application Support/Sidekey/Layouts/`. You can edit the files by hand and choose **Reload Layouts** to pick up the changes. Every file is checked each time it loads. A file with a problem is refused whole and reported in the menu and in the editor, where you can delete it.

## Launch at Login

- A **Launch at Login** item in the Sidekey menu starts Sidekey when you log in. It is off until you turn it on. If macOS needs your approval, System Settings opens at Login Items.

## Fix

- Apple Shortcut keys now run the shortcuts tool directly instead of through a shell.

## iPad and iPhone

The iPad and iPhone app is unchanged. Custom layouts need app build 5 or later, the same as the Citrix layout.

## Updating

Sidekey does not update itself. Quit Sidekey, download the new `Sidekey.dmg` and drag Sidekey to Applications again, replacing the old copy.
