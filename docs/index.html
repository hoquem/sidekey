Download Sidekey for Mac

Prop your iPad beside the keyboard. Whenever you switch apps on the Mac, the iPad shows keys for that app, and tapping a key runs the shortcut on the Mac.

Download Sidekey.dmg Release notes

You need an iPad with iPadOS 16 or later, a Mac with macOS 13 or later, and a USB cable between them or the same Wi-Fi network.

The Mac app is signed with Developer ID and notarized by Apple. Open the DMG, drag Sidekey to Applications and open it from there; it lives in the menu bar. Switch it on when macOS asks for Accessibility, then choose Pair iPad in its menu and type the code on your iPad.

If you installed Mac version 1.0.0, replace it: it had a security problem and was withdrawn.

The iPad app is in a private TestFlight beta and will come to the App Store. Until then you can build it from the source code.

How it works

  1. Sidekey on the Mac lives in the menu bar and watches which app is in front.
  2. Sidekey on the iPad finds the Mac over the USB cable when plugged in, or the same Wi-Fi network otherwise.
  3. Pair once. Choose Pair iPad in the Mac's Sidekey menu and type the code it shows into the iPad. Until an iPad is paired, the Mac sends it only its name and a pairing request and runs none of its taps. After that, the iPad connects to your Mac by itself.
  4. The keys change with the app. The top of the iPad shows the Mac app's icon, name and window title, so you always know where a tap will land.
  5. Every tap gets an answer. A key glows amber while the Mac works, lights up when the shortcut was sent, and shakes with the Mac's reason when it could not be.
  6. Only built-in actions. The Mac runs a key's action from its own layout, never an action sent over the network.
  7. Use a trusted connection. Traffic is not encrypted yet, so use Sidekey over USB or on a network you trust. See Privacy for what that means.
  8. Disruptive keys need a hold. Lock Mac, Interrupt, End Call, Telegram Lock and Xcode Clean fire only after a press and hold.

Apps without their own layout get these system keys. Do Not Disturb runs a shortcut named Toggle Focus, which you create in the Shortcuts app on your Mac.
